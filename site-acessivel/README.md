# Site Acessível sobre o Tropicália

## Sobre
Refatoração de site implementando recursos de acessibilidade no HTML, CSS e Java Script.

## Recursos de acessibilidade 
- Atributos ARIA;
- Alt;
- Tab-index;
- Menu de acessibilidade.

## Tecnologias utilizadas
- Bootstrap;
- ScrollReveal.js;
- HTML;
- CSS;
- JS.
